# Calculadora MEI

Calculadora simples e estática (HTML/CSS/JS puro, sem dependências) para o MEI estimar:

- O valor do DAS do mês, por categoria de atividade (Comércio/Indústria, Serviços ou ambos), com opção de ajuste manual.
- O limite anual de faturamento, proporcional aos meses de atividade no ano de abertura.
- O faturamento acumulado no ano e o percentual já utilizado do limite, com aviso visual ao se aproximar ou exceder o teto.

## Como usar

Basta abrir o arquivo [`index.html`](index.html) em qualquer navegador — não há build nem instalação de dependências.

## Aviso

Os valores padrão do DAS são atualizados anualmente (vinculados ao salário mínimo). Confirme os valores vigentes no portal do Simples Nacional antes de usar para decisões financeiras.
